# Wondering®

Ruang untuk hal-hal yang belum selesai dipikirkan.

Blog personal berbahasa Indonesia. Dibangun dengan Hugo + tema [Bear Blog](https://github.com/janraasch/hugo-bearblog), di-deploy ke Cloudflare Pages.

## Struktur

- `content/` — semua tulisan
- `layouts/` — override kecil dari tema (title browser)
- `themes/hugo-bearblog/` — tema (submodule)
- `hugo.toml` — konfigurasi situs

## Development

```
w                    # cd ke folder project
h                    # jalankan hugo server
```

Buka http://localhost:1313

## Deploy

Push ke branch `main` → Cloudflare Pages build otomatis.
